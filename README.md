# NOT MEMORY GAME — 新規衰弱プロトタイプ

散らばったカードを、1ターンに2つのフリップで公開してペアを作るブラウザゲームです。`notmemorygame` は開発中の暫定名称です。
今後のルール調整を行いやすいように、設定・見た目・ゲーム処理を分離しています。

## 起動方法

1. このフォルダを展開します。
2. `index.html` をダブルクリックします。
3. Chromeなどのブラウザでそのまま遊べます。

外部ライブラリやインターネット接続は不要です。

## ファイル構成

- `index.html`：画面の構造
- `styles.css`：デザイン、カードの見た目、アニメーション
- `config.js`：ライフ、得点、カードサイズ、特殊フリップ性能などの調整値
- `game.js`：ラウンド、ターン、判定、報酬、装備などのゲーム処理
- `GAMEPLAY_REVIEW.md`：根本的なゲーム性・システムの批判と改善案

## 現在のルール

- 実際のトランプ52枚を使用します。あらかじめランダムな並び順を1つ決めておき（例：最初のランクはA。ランダムな2スートが最初のペア）、ラウンドNの開始時に、その並びの先頭(N+1)枚をまるごと配り直します。
- ラウンド1は2枚、ラウンド2は3枚、ラウンド3は4枚…と、ラウンドが進むごとに盤面の枚数が1枚ずつ増え、最終ラウンドでは52枚になります。
- 新しいラウンドが始まるたびに、前のラウンドで見つけたカードも含めて全カードが裏向きに戻り、位置もランダムに配置し直されます（記憶のリセット）。
- **同じ数字（ランク）であれば、スート・色を問わずペアになります**（本来のトランプ神経衰弱と同じ仕様）。例：クラブの7とハートの7もペア成立します。
- 各ラウンドでは、カードの配置を先に確認してからフリップ1・2の装備を選びます。
- 表向きになったカードは、中央にランク・スートが大きく表示されます。
- 1ターンにフリップ1、フリップ2を順番に実行します。
- 2回のフリップ後、以前から表向きだったカードを含む未処理カード全体を判定します。
- ペアが1組以上なら勝利し、ペアは消えます。
- 複数ペアは `100 × ペア数²` 点です。
- ペアにならなかったカードは、判定後に裏向きへ戻ります。
- ペアが成立するとコンボが1増え、コンボ数と同じ量のライフを回復します（1コンボ目から+1、2コンボ目で+2、3コンボ目で+3…と伸びます）。**ライフの上限はなく、回復した分はそのまま貯蓄されます。** 失敗するとコンボは0に戻り、ライフを1失います。
- 現在はコンボ回復単体の手触りを検証するため、「様子見」（パス）は使用できません（`config.js`の`passEnabled: false`）。
- ライフ0で即ゲームオーバーです。
- 裏向きカードが1枚以下になるとラウンド終了です。
- 52枚のカードをすべて使い切るとゲームクリアです（全51ラウンド）。
- 毎ターン共通の3エネルギーを使えます。残りエネルギーは次のターンに全回復します。

## 特殊フリップ（現在バランス検証中のため一時停止）

特殊フリップ（ダブル・ラッキーストライク・パワーアタック）は、コンボ回復・様子見システムの効果を単体で検証するため、現在は報酬に出現しません（`config.js`の`rewardSkillIds`を空にしています）。通常フリップのみで遊べます。

## よく調整しそうな場所

`config.js` の以下を変更すると、ゲーム全体を触らずに調整できます。

```js
initialLives: 20,            // 初期ライフ
maxLives: Infinity,          // 最大ライフ（プレイテスト中は上限なし）
maxEnergy: 3,                // ターンごとの最大エネルギー
inventoryLimit: 4,           // 特殊フリップ所持上限
rewardEveryRounds: 2,        // 報酬が出る間隔
pairBaseScore: 100,          // ペア得点の基礎値
roundBonusMultiplier: 50,    // ラウンド突破ボーナス
passLifeCost: 1,             // 様子見1回あたりのライフ消費
passEnabled: false,          // 様子見の使用可否（プレイテスト中は不可）
powerRadiusInCardWidths: 2.25 // パワーアタックの半径
```

各フリップの消費エネルギーは `energyCost` で変更できます。たとえばパワーアタックの消費を2にする場合は、`config.js` の `power` を次のように変更できます。

```js
energyCost: 2,
```
